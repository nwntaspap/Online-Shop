# 🛍️ Online Shop

A simple responsive online shop layout built with **HTML, CSS, and JavaScript**.  
Features a **search bar** that filters products by name, brand, color, or price.

## 🚀 Features
- Responsive navigation with sidebar for mobile
- Product listing with hover effects
- Search filter (supports multiple words)

## 💻 Tech Stack
- HTML5
- CSS3 (Flexbox, Media Queries)
- Vanilla JavaScript

## 🔎 Demo
Try the search bar: type `nike white`, `adidas blue`, or `air force`.
